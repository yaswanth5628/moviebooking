# 🎬 Movie Booking System

A simple **Movie Ticket Booking System** developed in **Java** that demonstrates Object-Oriented Programming (OOP) concepts, menu-driven programming, and basic booking management. This project allows users to browse available movies, book tickets, and manage bookings through a console-based interface.

---

## 📖 Overview

The Movie Booking System is a Java application designed to simulate the basic functionalities of an online movie ticket booking platform. It is intended for learning Java fundamentals and applying concepts such as:

- Object-Oriented Programming (OOP)
- Classes & Objects
- Encapsulation
- Inheritance (if implemented)
- Collections
- Exception Handling
- File Organization
- Menu-Driven Programming

---

## ✨ Features

- 🎥 View available movies
- 🎟️ Book movie tickets
- 👤 Store customer details
- 💺 Seat booking simulation
- 💰 Ticket price calculation
- 📋 Display booking information
- ❌ Input validation for invalid choices
- 🖥️ Console-based user interface

## 🚀 Getting Started

### Prerequisites

- Java JDK 17 or later
- IntelliJ IDEA (Recommended)

---

### Clone the Repository

```bash
git clone https://github.com/yaswanth5628/moviebooking.git
```

Move into the project directory:

```bash
cd moviebooking
```

---

### Run the Project

Compile:

```bash
javac *.java
```

Run:

```bash
java Main
```

Or simply open the project in **IntelliJ IDEA** and run the `Main` class.
